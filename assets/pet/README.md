# 猫咪桌宠素材

## 已确认的角色基准

用户已确认 `keyframe.png` 为第一帧。它直接裁自第一版 `cat-atlas.png` 的左上角，裁切区域为 `(0, 0, 311, 310)`，没有重画。

- 保持这只猫的脸型、比例、毛色、纹路和手绘笔触，以及桌子、电脑、椅子和完整草席。
- 后续生成必须使用该原图作为角色参考，不接受仅凭文字重新生成的另一只猫。
- 所有动作共用这一张首尾帧；如需统一尺寸或留白，只处理一次基准图，再由所有动作复用。
- 每个动作 50 帧，前后各 5 帧过渡；状态变化先播放完当前动作，再经过共同首尾帧衔接下一动作。
- 举「奏」牌时身体保持侧坐，扭头看向用户；举牌序列不出现稿纸，任务完成序列不出现牌子。
- 休息姿势参考第一版第二行的后仰睡觉和短圆爪，不采用后来拉长手臂的版本。

## 动画与原画

`cat-atlas.png` 是第一版原画，4 行 × 4 列，分别为工作、睡觉、举「奏」牌、放下稿纸。原画由内置 imagegen 生成，提示词见 `prompt.txt`。

现在使用这些已确认的关键帧做双向光流插帧，没有重新生成角色。每段 50 帧包含原画和补间帧，并非 50 张独立手绘原画。姿势变化较大的过渡仍可能有局部形变。

- `keyframe.png`：已确认的原始基准图，不修改。
- `neutral.png`：统一尺寸和留白后的共同首尾帧。
- `frames/working/`、`frames/sleeping/`、`frames/permission_request/`、`frames/task_complete/`：运行时的四个 PNG 文件夹，各含 `0001.png` 至 `0050.png`。
- `working`、`sleeping`、`permission`、`complete` 的 `*-atlas.webp`：本地导出的图集，供制作和检查，不入库。
- 同名 `.webp`：本地导出的独立动画，不入库；`.json`：保留的帧数、关键帧位置与共同首尾校验记录。可用下方脚本重新生成预览文件。
- `src/lib/pet-player.ts`：主体循环、完成后等待、收尾后切换的播放逻辑。

动画每帧 80 毫秒，完整片段为 4 秒。同一状态循环主体；任务完成后停在稿纸落地的姿势。状态变化先完成当前主体和收尾，再进入最新状态。减少动态效果的系统设置使用静止姿势。

## 卡片配置

在「桌宠 → 编辑」中，为每个状态设置文件夹、进入片段、循环片段、退出片段和每帧毫秒数。文件夹留空使用内置素材，填写绝对路径则使用本地 PNG。

默认进入 1–5 帧、循环 6–45 帧、退出 46–50 帧，每帧 80 毫秒。勾选「主体播完停在末帧」可等待消息处理；否则重复循环。片段使用从 1 开始的闭区间，可留间隔，但不能重叠或越界。

PNG 按数字排序，支持 `1.png` 或 `0001.png`，不能缺号或重复。最多 240 帧，单帧不超过 1024×1024、4 MB，单状态不超过 64 MB、总计约 1600 万像素。保存时校验素材及共同首尾。素材帧数变化后，需重新检查目录并调整片段。

## 重新组装

Python 3.11+，在项目已有的 `.venv/` 或临时虚拟环境安装依赖：

```sh
python -m pip install -r scripts/pet-animation-requirements.txt
python scripts/build-pet-animation.py
```

脚本只读取原版关键帧，输出动画并检查 50 帧、共同首尾和安全留白。无需图像生成服务。
